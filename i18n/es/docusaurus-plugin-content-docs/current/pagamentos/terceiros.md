# Pagos que involucran a terceros

**Situación:** alguien pide pagar a una cuenta distinta de la acordada, o el pago llega de una persona diferente del comprador.

## Señales de alerta
- Cambio inesperado del beneficiario, destino o datos de cualquier método de pago previamente registrado o acordado para la operación.
- Presión para pagar rápidamente o continuar fuera del flujo acordado.
- Solicitud de reembolso a un destino diferente del origen del pago o fuera del método acordado.

## Qué hacer
1. No consideres que el nombre o identificador mostrado por un banco, proveedor de pagos o billetera demuestra por sí solo que la operación es segura.
2. Compara los datos del beneficiario, destino y método de pago con los previamente registrados o formalmente acordados para la operación.
3. Si existen diferencias, **detén el pago** y utiliza el canal de soporte o disputas correspondiente.
4. Conserva comprobantes y mensajes sin publicar datos personales o financieros.

Las cuentas conjuntas, empresariales y los pagos de terceros pueden tener usos legítimos. Una diferencia exige verificación, no una acusación automática de fraude.

**Estado:** orientación general; no afirma que el protocolo verifique la titularidad de cuentas, billeteras u otros destinos de pago.
